# EasyEDA Pro Design Source

This directory contains the native EasyEDA Pro project source for the
JF Audio Version 2 (MRK II) custom PCB.

## Project File

`JF_Audio_V2_MRKII_EasyEDA_Pro.epro2`

The project file contains the editable design associated with the Version 2
PCB that was physically manufactured, assembled, and tested.

The source is preserved as the original Version 2 design revision and may
contain design decisions or limitations that were identified during hardware
testing.

Tool-independent fabrication and assembly outputs are available in the
`Manufacturing/` directory.
