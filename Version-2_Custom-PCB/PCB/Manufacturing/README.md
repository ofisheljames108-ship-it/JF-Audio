# Version 2 PCB Manufacturing Files

This directory contains the design and manufacturing files associated with
the JF Audio Version 2 (MRK II) custom PCB.

These files represent the Version 2 board revision that was physically
manufactured, assembled, and tested. They are preserved as part of the
engineering history of the project and are not intended to represent future
JF Audio PCB revisions.

## Contents

- **Source/** — Editable EasyEDA PCB design files
- **Gerbers/** — PCB fabrication files, including drill information
- **BOM/** — Bill of materials exported for the manufactured PCB
- **Pick-and-Place/** — Component placement data for PCB assembly

Human-readable schematic exports and PCB images are available elsewhere in
the Version 2 documentation.

## Revision

**JF Audio Version 2 / MRK II**

Later JF Audio versions may use substantially revised PCB architectures.
