# JF Audio Version 1 - Prototype

## Overview

Version 1 of the JF Audio Bluetooth speaker was built as a proof-of-concept prototype using off-the-shelf modules and hand-wired connections. The goal was to build a fully functional portable Bluetooth speaker while learning about audio amplifiers, lithium-ion battery systems, soldering, and enclosure design.

---

## Objectives

- Build a working portable Bluetooth speaker.
- Learn basic audio amplifier circuitry.
- Gain experience soldering electronic components.
- Design and assemble the enclosure.
- Prepare for a future custom PCB.

---

## Features

- Bluetooth audio streaming
- Stereo audio output
- Portable battery-powered design
- 3D-free enclosure built from a modified food container

---

## Lessons Learned

- Power supply quality affects audio noise.
- Speaker placement affects sound quality.
- Proper wire management makes assembly much easier.
- PCB design offers a cleaner and more reliable solution than point-to-point wiring.
